# 학생 여정 UX 루브릭 — 2026-09-13

- 페르소나: 아두이노·배선·코딩이 처음인 중학교 2학년. 탐구 주제 하나("실 길이에 따라 진자 주기가 달라질까")를 들고 옴. 크롬, 학교 노트북, 우노 1대.
- 대상: 배포본 https://shy.ai.kr/How_To_Use_Arduino/
- 여정: 아이디어 찾기 → 레시피 고르기 → 준비물 → 배선 → 코드 → 탐구 설계 → 측정 → 데이터 화면 → 회차 넣기 → 레시피로 돌아가 조건 바꾸기 → 다시 측정 → 회차 더하기 → 그래프·CSV
- 채점: 요소마다 7점 만점. 4점 이하는 고친다.

| 점수 | 뜻 |
|---|---|
| 7 | 막힘 없음. 다음에 할 일이 화면에 있고 한 번에 이해됨 |
| 5~6 | 잠깐 멈추지만 화면 안에서 스스로 풀림 |
| 3~4 | 화면 밖 도움(선생님·검색)이 있어야 넘어감, 또는 되돌아가기가 불편함 |
| 1~2 | 진행 불가, 또는 모아 둔 것을 잃음 |

## 요소

| # | 요소 | 무엇을 보나 |
|---|---|---|
| E1 | 주제로 레시피 찾기 | 탐구 문장 검색 → 맞는 레시피가 상위에, 아니면 비슷한 것 안내 |
| E2 | 한눈에 보기 | 무엇을 재고 무엇이 필요한지 첫 화면에서 잡히는가. 다음 단계가 보이는가 |
| E3 | 준비물 | 서랍에서 고를 수 있는 이름·값. 저항 색띠 등 |
| E4 | 배선 | 단계 그림·체크·전원 넣기 전 점검. 한 칸 밀림을 되짚을 수 있는가 |
| E5 | 코드 넣기 | IDE 순서, 라이브러리, 속도, 첫 실행 문제 해결, 처음 나온 값 점검 |
| E6 | 탐구 설계 | 독립·종속·통제 변인, 조건 수, 반복 횟수가 문장으로 있는가 |
| E7 | 측정 → 데이터 화면 이동 | 링크가 속도·열 이름·센서를 실어 가는가. USB/붙여넣기 안내 |
| E8 | 회차 넣기와 읽기 | 붙여넣기(또는 USB) → 통계·그래프가 바로 뜨는가. 오류 문구 이해 가능 |
| E9 | 레시피로 되돌아가기 | 데이터 화면에서 원래 레시피·설계로 가는 길이 있는가. 회차가 유지되는가 |
| E10 | 조건 바꿔 재실험 안내 | 무엇을 얼마나 바꿀지, 코드의 어느 줄인지, 몇 번 반복인지가 있는가 |
| E11 | 회차 누적·비교 | 2회차 이상 넣기, 조건 값 열, 회차 비교 그래프, CSV |
| E12 | 진행·자료 보존 | 새로 고침·뒤로 가기·탭 이동 뒤에도 배선 진행과 회차가 남는가 |
| E13 | 문구 | 중2가 한 번에 읽히는가. 용어에 뜻이 붙어 있는가 |
