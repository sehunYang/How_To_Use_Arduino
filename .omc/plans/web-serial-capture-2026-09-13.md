# USB 직접 수신(Web Serial) 전환 검토 — 2026-09-13

## 결론

가능하며, 설치 없이 됩니다. 붙여넣기를 없애는 "전환"이 아니라 **USB 수신을 기본 경로로 올리고 붙여넣기를 대안으로 남기는 추가**가 맞습니다.

근거:
- 사이트는 GitHub Pages(HTTPS)라 Web Serial API의 보안 컨텍스트 조건을 이미 만족합니다.
- 스케치를 올린 컴퓨터에는 아두이노 IDE가 깔려 있으므로 Windows·macOS·Linux 데스크톱이고, 크롬·엣지·웨일 중 하나는 있습니다. 즉 USB 수신이 되는 기기가 실험 자리에 반드시 있습니다.
- 스케치 94개가 9600, 10개가 115200 baud이며 `recipe.baudRate`에 값이 있어 속도를 학생이 고를 필요가 없습니다.
- 모든 스케치가 setup()에서 CSV 헤더 줄을 먼저 찍습니다. 포트를 열면 DTR로 우노가 리셋되어 헤더부터 다시 나오므로, 지금 파서(`convertSerialTextToCsv`)를 그대로 물릴 수 있습니다.
- 분석 화면의 회차(trial) 상태는 "문자열 → 파서 → addTrial" 한 길이라, 수신 버퍼를 같은 길로 넣으면 통계·그래프·CSV 코드는 손댈 것이 없습니다.

## 제약과 대응

| 제약 | 영향 | 대응 |
|---|---|---|
| Firefox·Safari·iOS·Android 크롬은 Web Serial 미지원 | 그 브라우저에서는 버튼이 안 보임 | 기능 감지 후 버튼 숨기고 붙여넣기 유지. 한 줄 안내 |
| IDE 시리얼 모니터가 포트를 잡고 있으면 브라우저가 못 엶 | 첫 시도에서 가장 흔한 실패 | "시리얼 모니터를 닫고 다시 누르세요" 오류 문구 + 첫 실행 문제 해결 항목 추가 |
| 브라우저가 포트를 쥔 동안 IDE 업로드 실패 | 코드 고치고 다시 올릴 때 막힘 | 수신 멈춤 시 반드시 포트 close, 화면 이탈 시 자동 close |
| 속도 불일치 시 깨진 글자 | 학생은 원인을 모름 | 수신 줄이 UTF-8이 아니거나 3줄 연속 CSV가 아니면 "속도를 N으로" 제안 |
| 수신 중 케이블 뽑힘 | 스트림 에러 | 받은 데이터는 보존하고 "다시 연결" 안내 |
| 자동화 테스트에서 실제 포트 없음 | E2E 불가 | `navigator.serial` 목으로 단위 테스트, 실기는 우노 1대로 수동 검증 |
| 스펙 범위 밖 항목 "브라우저 내 업로드" | 읽기는 업로드가 아니므로 저촉 없음 | 스펙에 "USB 읽기는 범위 안" 한 줄 추가 |

## 단계

### 1단계 — 최소 기능 (2026-09-13 구현, 실기 검증 대기)
- `src/lib/webSerial.ts`: 지원 감지, 열기(baud), DTR 리셋으로 헤더부터 받기, 줄 단위 스트림, 멈춤/닫기, 오류 → 학생 문구 매핑.
- `src/components/SerialCapturePanel.tsx`: 받기 패널. 화면 이탈·버리기·한계 도달·포트 못 닫음까지 처리.
- `DataAnalysisPage`에 "USB로 받기" 패널: 포트 고르기 → 받는 줄 수와 마지막 몇 줄 미리보기 → 멈춤 → "회차로 넣기". 넣기는 기존 addTrial 경로.
- MeasurePage 링크를 `/data-analysis?recipe=<id>`로 바꿔 baud와 기대 헤더를 넘김.
- firstRun 문제 해결에 "포트가 사용 중" 항목.
- 테스트: 줄 분리기, 오류 매핑, 목 포트로 받기→회차 넣기 흐름.

### 2단계 — 레시피를 아는 실시간 점검
- `firstReading.ts` 점검표를 수신 줄에 실시간 적용(예: -127.00 즉시 경고).
- 기대 헤더와 다르면 "다른 레시피 코드가 올라가 있음" 경고.
- 회차 자동 구분: 받기 시작~멈춤 한 번이 회차 하나.

### 3단계 — 선택
- Android 태블릿이 교실에 있으면 WebUSB 폴리필(web-serial-polyfill) 검토. 정품 우노(ATmega16U2)만 되고 CH340 호환보드는 안 됨.
- 학교 관리 크롬이면 `SerialAllowAllPortsForUrls` 정책으로 포트 선택창 생략 가능.

## 검증 계획
- 단위: vitest, 목 `navigator.serial`.
- 실기: 우노 + 9600 레시피 1개, 115200 레시피 1개. IDE 모니터 열린 채 시도, 수신 중 케이블 뽑기, 잘못된 속도.
- 브라우저: 크롬, 엣지, 웨일 각 1회. Firefox에서 버튼 숨김 확인.
