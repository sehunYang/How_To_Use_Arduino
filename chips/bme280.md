# BME280 Wokwi chip

This is an in-repository, auditable I2C model for sketches using
`Adafruit_BME280`. It implements the `0x76` address, chip identification,
Bosch reference calibration coefficients, soft reset, control/config/status
registers, register auto-increment, and the packed pressure/temperature/humidity
sample window.

The three controls are raw ADC counts because that is the BME280 register
contract. With the fixed coefficients, the defaults produce approximately
25.1 °C and 1006.5 hPa; humidity is deterministic but intended for functional
simulation rather than calibration work.

Limitations:

- I2C address `0x77`, SPI, conversion timing, standby timing, filtering, and
  power-mode energy behavior are not modeled.
- Measurement conversion is immediate, so the status register always reports
  ready.
- Raw controls do not enforce physically correlated environmental values.
- This chip is suitable for sketch/control-flow simulation, not sensor
  accuracy validation.
