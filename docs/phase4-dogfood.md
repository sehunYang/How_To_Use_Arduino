# Phase 4 저작 도구 실측 기록

Phase 4의 PL6 게이트는 자동 테스트가 아니라 실제 사용자가 관리자 화면만 사용해 수행하는 시간 측정이다. 이 문서는 측정값을 꾸며내지 않고 동일한 방식으로 기록하기 위한 체크리스트다.

## 측정 순서

1. 배포 또는 에뮬레이터의 빈 데이터에서 P1을 먼저 작성한다. P1 시간은 학습 구간으로 기록하되 판정에서 제외한다.
2. 소스 코드를 수정하지 않은 상태에서 E5를 새 레시피로 작성한다.
3. 배선 이미지, 스케치, 수업 시나리오, UI 입력, 검증 대기·수정 시간을 각각 기록한다.
4. 기기 검토와 코드 주석 검토를 완료하고, 검증 원장의 현재 해시가 통과한 뒤 게시한다.
5. 로그아웃한 학생 화면에서 E5가 즉시 보이는지 확인한다.
6. E5 총 시간이 150분 이하인지 판정하고 `E5 시간 × 34`를 Phase 5 예상 일정으로 기록한다.
