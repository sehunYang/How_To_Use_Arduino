# 검색 테스트 문장 (`search-sentences.json`)

45개 문장입니다. 튜닝용 30개(`split: "tuning"`)와 홀드아웃 15개(`split: "holdout"`)로 나뉩니다.
`A1.1`("상위 3위 안에 반환")의 합격 조건 자체를 정의하는 데이터입니다.

## 출시 전 할 일

현재 45개 전부 `source: "author"`, 즉 작성자가 지어낸 문장입니다.

`PL8`(계획서 참조)은 최소 15개는 실제 학생이 쓴 문장이어야 한다고 정해 두었습니다. 이유는 프리모템 1번입니다. 문장과 동의어 사전을
같은 사람이 모두 쓰면 매칭률은 작성자의 자기일관성만 재는 셈이라, 학생 어휘와의 격차가 드러나지 않기 때문입니다.

처리 순서:

1. Phase 5 착수 전, 실제 학생 5~10명에게 "아두이노로 뭘 해 보고 싶은지 한 문장으로 써 보세요"라고 물어 문장을 받습니다.
2. `holdout` split의 최소 15개를 학생이 실제로 쓴 문장으로 바꾸고 `source: "student"`로 표기합니다. 튜닝셋도 가능하면 일부 바꿉니다.
3. `npm run verify:holdout`을 학생 문장으로 다시 실행해 실제 매칭률을 확인합니다.

이 작업 없이 파일을 "완료"로 처리하면 `A1.1` 검증의 의미가 없어집니다.

## 필드

| 필드 | 설명 |
|---|---|
| `sentence` | 학생이 입력했다고 가정한 자유 문장 |
| `expectedRecipeId` | 기대하는 레시피/센서 예제 ID |
| `source` | `"author"` (임시 문장) \| `"student"` (실제 학생 작성, 아직 0건) |
| `split` | `"tuning"`(동의어 사전 보강용, 30개) \| `"holdout"`(튜닝에는 절대 쓰지 않음, 15개, 출시 직전 1회만 측정) |

## 사용

```bash
npm run verify:matching -- --min 83   # 튜닝셋 매칭률 게이트
npm run verify:holdout -- --min 73    # 홀드아웃 매칭률 게이트 (출시 직전 1회)
```
