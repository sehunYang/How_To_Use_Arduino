# 검색 테스트 문장 (`search-sentences.json`)

45개 문장 — 튜닝용 30개(`split: "tuning"`) + 홀드아웃 15개(`split: "holdout"`).
`A1.1`("상위 3위 안에 반환")의 합격 조건 자체를 정의하는 데이터입니다.

## 필드

| 필드 | 설명 |
|---|---|
| `sentence` | 학생이 입력했다고 가정한 자유 문장 |
| `expectedRecipeId` | 기대하는 레시피/센서 예제 ID |
| `source` | `"author"` (플레이스홀더) \| `"student"` (실제 학생 작성, 아직 0건) |
| `split` | `"tuning"`(동의어 사전 보강용, 30개) \| `"holdout"`(튜닝에 절대 미사용, 15개, 출시 직전 1회만 측정) |

## 사용

```bash
npm run verify:matching -- --min 83   # 튜닝셋 매칭률 게이트
npm run verify:holdout -- --min 73    # 홀드아웃 매칭률 게이트 (출시 직전 1회)
```
